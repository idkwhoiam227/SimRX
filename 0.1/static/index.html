About

What SimRX is, where the data comes from, and credits

SimRX is an unofficial fan project and is not affiliated with SimTX. It connects to the SimTX server as an anonymous listener (no account) and records what the server sends to every connected client: who is transmitting, on which frequency and mode, with what power and from which in-game position, and which receivers are connected. From that it builds the live view, history, statistics, callsign profiles and the map.

Positions are the in-game (virtual) locations of transmitters. SimRX stores no personal information about players: no player accounts, no real names, no network addresses. A transmission is timed from the moment SimRX first sees it, so history is approximate: it can start a little late, and there are gaps when SimRX was offline.

SimRX is made with qrmcat's permission. If she wants it taken down, I'll comply.

Band plan: SDR++ by Alexandre Rouma (Ryzerth). Maps: © OpenStreetMap contributors, drawn with Leaflet.
